Ask-the-Image: Voice-Driven Visual Question Answering App
Ask-the-Image is an innovative AI-powered prototype that brings together computer vision, speech recognition, and text-to-speech synthesis. With a simple voice command and an uploaded image, you can ask questions and hear the AI respond — both visually and audibly.

This lightweight multimodal app demonstrates how modern AI components can be combined for interactive user experiences.

🔍 What Can It Do?
🎤 Voice-Activated Questions: Speak your question (max 10 seconds) — it's converted to text using OpenAI’s Whisper ASR model.

🖼️ Image Understanding: Upload an image and the app uses BLIP-2 (powered by FLAN-T5) to interpret and answer your question.

🔊 Spoken Responses: The generated answer is read aloud using gTTS, making the experience fully interactive.

🧩 Modular Architecture: Built with separation of concerns – each component lives in its own script (asr.py, qa.py, tts.py, app.py).

⚙️ Tools & Technologies
Gradio – Easy-to-use web interface

Whisper-small – State-of-the-art speech-to-text

BLIP-2 + FLAN-T5 – Vision-to-language model

gTTS (Google Text-to-Speech) – Speech synthesis

Python, PyTorch, Hugging Face Transformers
